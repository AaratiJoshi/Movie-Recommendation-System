# 🎬 Movie-Recommendation-System

A content-based Movie Recommendation Web Application built using Machine Learning and Streamlit.

## 🌐 Live Demo

[Click Here to Open the App](https://movie-recommendation-system-mfop.onrender.com/)

## 🚀 Features

- Interactive and clean UI
- Movie poster fetching using OMDb API
- Fast recommendation system using cosine similarity
- Deployed on Render

## 🛠️ Tech Stack

- Python
- Streamlit
- Pandas
- Scikit-learn
- Pickle
- Requests API

## 📂 Dataset

TMDB 5000 Movies Dataset

## ⚙️ How It Works

- Data preprocessing and cleaning
- Feature vector creation using tags
- Cosine similarity calculation
- Recommendation generation based on similarity scores
